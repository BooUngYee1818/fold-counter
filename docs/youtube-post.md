## 6. 업로드 순서 / Upload steps
1. 깃허브에서 **Releases → Create a new release → 태그 `v0.1.0` → Publish** (APK와 IPA 가 자동으로 붙음) → Releases 주소 복사
2. YouTube Studio → 만들기 → **동영상 업로드** → `FoldCounter-shorts-ko-en.mp4` 선택 (세로 영상이라 자동으로 Shorts 로 등록)
3. 제목(1), 설명(2), 태그(3) 붙여넣기 → 아동용 아님 → 공개 → 게시
4. 게시 후 **댓글 고정**(5) 과 **커뮤니티 탭 게시글**(4) 올리기
5. 인스타그램 / 틱톡은 같은 영상 + `docs/promo.md` 의 캡션 사용
